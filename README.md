# KrishiAI — Smart Agriculture Decision Engine & Blockchain Ecosystem

KrishiAI is an AI-powered precision agriculture platform designed for Indian farmers, combining IoT farm telemetry, multi-modal diagnostics, smart irrigation, and blockchain-verified fertilizer prescriptions.

## 📁 Repository Structure
- **`krishi_ai_app/`**: Flutter Cross-Platform Mobile Application (Android / iOS).
- **`krishiAi-main/`**: Web Application & Node.js Backend with MST Blockchain Engine.
- **`main.dart`**: Unified Flutter Application Architecture.
- **`run.txt`**: Complete setup and startup command guide.

## 🚀 Getting Started
Refer to `run.txt` for detailed startup commands across all services.
